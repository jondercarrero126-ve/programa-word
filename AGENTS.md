# AGENTS.md

## Project Overview
PySide6 Qt GUI application for thesis management. Entry point: `main.py` -> `Login` -> `Principal` class -> `ui_principal.py`.

## Tech Stack
- **Framework**: PySide6 (Qt for Python)
- **Database**: MySQL (mysql-connector-python)
- **Document Processing**: python-docx
- **Virtual Environment**: `env/` directory

## UI Generation (Critical)
UI files are generated from Qt Designer `.ui` files. After editing `.ui` files, regenerate:

```bash
# From project root with virtual environment activated
pyside6-uic .\UI\principal.ui > .\UI\ui_principal.py
pyside6-uic .\UI\login.ui > .\UI\ui_login.py
pyside6-rcc .\UI\recursos.qrc -o .\UI\recursos_rc.py
```

**IMPORTANT**: Generated files (`UI/ui_principal.py`, `UI/ui_login.py`, `UI/recursos_rc.py`) should NEVER be edited manually.

## PySide6 Development Rules

### Architecture Pattern
- **MVC Pattern**: Separate UI (generated), business logic (controllers), data (database)
- **Signal/Slot**: Use Qt signals for inter-component communication
- **QThread**: Use for long-running operations (e.g., file import)

### Code Conventions
1. **Class Naming**: `PascalCase` (e.g., `TesisController`, `WordExtractor`)
2. **Method Naming**: `snake_case` with underscore prefix for private methods (e.g., `_cambiar_pagina`)
3. **UI Methods**: Generated by `pyside6-uic`, do not modify
4. **Imports**: PySide6 modules from `PySide6.QtWidgets`, `PySide6.QtCore`, `PySide6.QtGui`

### Common Patterns
```python
# Thread worker for long operations
class ImportWorker(QThread):
    finished = Signal(dict)
    error = Signal(str)

# Controller with signals
class TesisController(QObject):
    tesis_changed = Signal(list)
    error_occurred = Signal(str)

# UI class inheritance
class Principal(QMainWindow, Ui_MainWindow):
    def __init__(self, usuario):
        super().__init__()
        self.setupUi(self)
```

### Layout Guidelines
- Use Qt Designer for layout design
- Prefer `QVBoxLayout` and `QHBoxLayout`
- Use `QStackedWidget` or `QTabWidget` for multi-page interfaces

## Testing
Run pytest from project root with virtual environment:
```bash
env\Scripts\python.exe -m pytest tests/ -v
```
- `tests/test_database.py` - 14 tests (Database class)
- `tests/test_extractor.py` - 12 tests (WordExtractor)
- `tests/test_gui.py` - 21 tests (Login, Principal, ImportWorker, TesisController)
- `scripts/test_completo.py` - Manual test script (requires user input)

## Database Schema
Main tables: `usuarios`, `tesis`, `capitulos`, `referencias`. See `scripts/init_database.py` for schema.

## Common Tasks
- **Add new page**: Edit `UI/principal.ui` in Qt Designer, regenerate `UI/ui_principal.py`
- **Add new widget**: Create in Qt Designer or Python class, connect via signals
- **Import thesis**: Uses `WordExtractor` + `TesisController` with QThread
- **Database changes**: Edit `database/__init__.py`
